# GugaLauncher — GugaEFMI 使用说明

[English](README.md) | [繁體中文](README.zh-TW.md) | 简体中文

GugaLauncher 的设计目的，是将原本需要手动操作 **XXMI／EFMI 与官方 GRYPHLINK 启动器**的步骤简化，整合成一键启动流程。

完成首次设置后，只需双击 **GugaEFMI**，并在 Windows 提示时批准管理员权限，工具就会自动协调官方启动器与原版 XXMI／EFMI，启动终末地并交由 EFMI 加载 mod，减少每次游玩前的重复操作。

GugaLauncher 使用 C# 开发，负责启动前检查与进程协调；mod 的准备与注入仍由原版 XXMI／EFMI 处理。本工具不包含游戏、XXMI、EFMI 或 mod，也不是游戏官方启动器。

## 使用前准备

- Windows 64 位环境。
- 已安装终末地及官方 **GRYPHLINK** 启动器。
- 已安装 **XXMI 2.4.9**，并完成 EFMI 与所需 mod 的准备。本版会检查 XXMI 可执行文件版本 `2.4.9.0`，目前不接受其他版本。
- 启动时可以批准 Windows 管理员权限提示。

发布包已包含 .NET Runtime，**不需要另外安装 Python 或 .NET**。

先将整个 ZIP 解压到固定位置，再开始设置。不要直接在压缩包内运行，也不要只取出其中的 `.exe`。

## 首次设置

### 1. 输入三个安装文件夹

双击主文件夹中的 **`Setup.cmd`**，在打开的 PowerShell 窗口依次输入：

| 项目 | 绝对路径示例 | 如何确认位置 |
| --- | --- | --- |
| XXMI | `C:\XXMI Launcher` | 包含 `Resources` 文件夹与 `XXMI Launcher Config.json`；可执行文件位于 `Resources\Bin` |
| 终末地 | `C:\Arknights Endfield` | 直接包含 `Endfield.exe` 的那一层 |
| GRYPHLINK | `C:\GRYPHLINK` | 包含 `Launcher.exe` 与官方版本子文件夹 |

**以上只是示例，不是默认安装位置。** 请填写自己的实际文件夹，不要选择 `.exe`，也不要选择 `Endfield_Data` 或 `Mods`。可以从文件资源管理器复制完整路径；路径两侧的双引号可以保留。

输入路径时留空按 Enter 会取消。三个路径通过文件检查后会自动保存。

### 2. 按提示设置 XXMI

先保留设置窗口，打开 XXMI、选择 **EFMI**，再进入齿轮 **“设置”**。以下名称对应 XXMI 中文界面。

**“通用”→“启动设置”**

1. 将“游戏启动”暂时选为“直接”。
2. 把出现的“启动方式”设为 **Native**。
3. 再将“游戏启动”改回 **“自定义”**。此时“启动方式”会隐藏，属于正常显示行为。
4. 将 GugaLauncher 设置窗口显示的**整行命令**粘贴到“启动命令”。保留双引号与最后的 `bridge`；不要改填 `Start.cmd` 或 `XXMI Launcher.exe`。
5. “游戏进程启动等待超时”填写 **60** 或更大，单位为秒。
6. “自定义游戏进程可执行文件名称”保持**不勾选**，保留默认的 `Endfield.exe`。

其他选项卡请按下表设置：

| 选项卡 | 字段 | 设置 |
| --- | --- | --- |
| EFMI | XXMI DLL 注入模式 | 选“注入”（英文 Direct） |
| 启动器 | 自动更新 | 取消勾选 |
| 高级 | 启动前命令、加载后命令、注入库 | 取消启用；不必删除原有文字 |

XXMI 的游戏文件夹须与第一步输入的位置相同。以上是当前版本的兼容性要求；GugaLauncher 不会替你修改 XXMI 设置。

### 3. 按 Enter 检查并完成

1. 关闭 XXMI 设置窗口并**正常退出 XXMI**。如果仍在系统托盘中，请从系统托盘退出。
2. 回到原来的 PowerShell 窗口，按 **Enter** 检查。
3. 如果提示问题，按提示修正后再次按 Enter；不必重新输入三个路径。输入 `Q` 可取消检查，已保存的路径会保留。
4. 显示 **OK** 后，程序会在主文件夹中自动创建 **`GugaEFMI.lnk`**，并使用终末地图标。
5. 按任意键关闭设置窗口。

快捷方式图标来自你安装的 XXMI；找不到图标时会提示缺少文件，设置仍会保留。此流程**不修改原版 `EFMI Quick Start` 快捷方式**。

## 日常启动

**确认游戏与 XXMI 已正常退出 → 双击 `GugaEFMI` → 批准管理员提示 → 等待游戏。**

- 设置会保留，下次不必重新运行 Setup。
- 官方 GRYPHLINK 可以保持打开；未打开时工具会尝试启动它。如果需要登录或更新，请先完成官方流程。
- 要使用本版协同流程，请从 **GugaEFMI** 进入。原版 XXMI 可用于管理设置，但其“启动”按钮与原版 EFMI Quick Start 不会建立本版所需的前置会话。
- 如果检测到已有游戏或 XXMI 进程，本工具会停止并提示，不会替你强制结束它们。

### 为什么会看到 PowerShell 与管理员提示？

GugaEFMI 通过 PowerShell 启动协同程序；当前协同流程需要管理员权限访问官方进程，因此会出现 Windows **UAC** 提示。

批准后，普通窗口会交接到管理员窗口并退出，因此可能短暂看到两个窗口。**游戏进程创建成功后，启动窗口会自动关闭**；如果失败或取消提权，会保留消息供阅读。

窗口关闭代表进程创建流程完成，并不能单独证明 mod 已正常显示；请以游戏画面确认。

### 杀毒软件出现警告时怎么办？

PowerShell、管理员权限、未签名文件，以及原版 EFMI 用于加载 mod 的 DLL 注入行为，都可能引起安全软件注意。但**不能仅因工具用途就认定所有警告都是误报**。

请确认文件来源，记下检测名称与被拦截的文件路径；不确定时先停止并保留消息。使用本工具不需要停用杀毒软件，也不应将整个磁盘加入排除项。

相关官方说明：[Windows UAC](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/settings-and-configuration)、[Microsoft 文件分析与疑似误报提交](https://www.microsoft.com/en-us/wdsi/filesubmission/?persona=HomeUser)。本工具不会自动提交文件。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 找不到必要文件 | 按第一步的文件夹特征重新确认，不要选到可执行文件或下一层文件夹 |
| 提示 XXMI 或游戏正在运行 | 正常退出后再试；不要连续重复点击 |
| 提示缺少前置检查会话 | 改用本版 GugaEFMI，不直接运行 `bridge`、原版启动按钮或原版 Quick Start |
| 设置检查不通过 | 按错误提示核对字段，保存并退出 XXMI 后，在原设置窗口按 Enter 重新检查 |
| 官方启动器未就绪 | 先完成官方登录或更新，再重试；不要自行修改进程权限或停用保护 |
| 想再次查看设置命令 | 运行 `Instructions.cmd`；命令会根据当前程序位置生成 |
| 移动了 GugaLauncher 文件夹 | 重新运行 Setup，更新 XXMI 命令并重新生成快捷方式 |
| 窗口显示错误 | 保留完整消息供排查；提供日志前先遮盖个人路径与账号信息 |

## 文件用途与隐私

| 文件／文件夹 | 用途 |
| --- | --- |
| `Setup.cmd` | 首次设置、按 Enter 重新检查、生成快捷方式 |
| `GugaEFMI.lnk` | 设置成功后生成的日常启动快捷方式 |
| `Start.cmd` | 相同协同流程的备用启动入口 |
| `Instructions.cmd` | 重新显示设置指引与命令 |
| `Check.cmd` | 只检查，不启动游戏 |
| `Offline-Tests.cmd` | 开发／排查使用的离线测试，不是启动入口 |
| `app/` | 程序及随附的 .NET Runtime；请完整保留 |
| `src/` | C# 源代码 |
| `PACKAGE-MANIFEST.json` | 初始发布文件的 SHA256 清单；不是数字签名 |
| `LICENSE`、`runtime-licenses/` | 许可与第三方声明 |

干净的发布包不包含玩家路径、账号、mod、日志或已配置的快捷方式。首次设置后生成的 `app/settings.json`、设置备份、`app/local-errors.log` 与快捷方式可能包含本机路径，**分享时请使用原始发布 ZIP，不要直接压缩已使用的文件夹**。

GugaLauncher 不移动原版 Mods；原版 XXMI／EFMI 仍会按自身设置进行必要的配置保存与 mod 处理。

## 适用范围

兼容性取决于游戏、启动器、XXMI／EFMI、mod 与系统环境。离线检查不能代替游戏内验证，不保证适用于所有电脑或未来版本。

本工具的防重复检查只涵盖自身的协同入口。原版 XXMI 的行为没有被修改；直接使用其他入口，或在启动过程中同时从其他程序启动游戏，仍可能绕过检查。启动时请只使用一个入口。
